# Početni izvori

## Osnova RAG sistema

- Lewis et al., *Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks* — definicija RAG pristupa i spajanja parametarske i neparametarske memorije.
- Robertson i Zaragoza, *The Probabilistic Relevance Framework: BM25 and Beyond* — teorijska osnova BM25.
- Cormack, Clarke i Buettcher, *Reciprocal Rank Fusion Outperforms Condorcet and Individual Rank Learning Methods* — izvor za RRF.
- Johnson, Douze i Jégou, *Billion-scale Similarity Search with GPUs* — FAISS i vektorska pretraga.

## Modeli i evaluacija

- Günther et al., *Jina Embeddings 2* — embedding porodica korišćena u implementaciji.
- Thakur et al., *BEIR* — poređenje sparse/dense/reranking retrievala i evaluaciona praksa.
- Qwen Team, *Qwen2.5 Technical Report* — porodica generativnog modela korišćena u baseline-u.

## Softver i podaci

- Docutils reStructuredText dokumentacija — RST parser i doctree.
- FAISS dokumentacija i izvorni repozitorijum.
- SQLite FTS5 dokumentacija.
- OpenAI `tiktoken` repozitorijum.
- CPython `Doc/` snapshot i Python PEP snapshot na commitovima navedenim u `data/system_inventory.json`.

BibTeX zapisi nalaze se u `references.bib`. Pre konačne predaje proveriti format koji zahteva fakultetski šablon.
